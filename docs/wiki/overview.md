# Overview

_Generated by Forge from `main` at `8a6ac81`._

ShopBridge is an ASP.NET Core web API designed for inventory management. It provides a RESTful interface to manage products and inventory operations, built with Entity Framework Core for data persistence and Swagger for interactive API documentation. The application follows a layered architecture with repositories, services, and middleware for clean separation of concerns and maintainability.

## Key Features

- **RESTful API** – Complete inventory management endpoints for CRUD operations
- **Entity Framework Core** – Object-relational mapping with SQL Server database support
- **Swagger Documentation** – Interactive API explorer available at the application root
- **AutoMapper** – Automatic object-to-object mapping between entities and DTOs
- **Global Error Handling** – Centralized middleware for consistent error responses
- **Dependency Injection** – Built-in ASP.NET Core DI for loose coupling and testability

## Project Structure

The application is organized into logical layers:

- **Controllers** – HTTP request handlers and routing
- **Models** – Domain entities representing database tables
- **DTO** – Data Transfer Objects for API contracts
- **Repositories** – Data access abstraction layer
- **Middlewares** – Request/response processing pipeline
- **Migrations** – Entity Framework database schema changes

Configuration files (`appsettings.json`, `Startup.cs`) define database connections, service registration, and middleware setup.

## Getting Started

To run ShopBridge locally, you'll need:

- .NET Core 3.1 SDK or later
- SQL Server instance
- Connection string configured in `appsettings.json`

The API is self-documenting through Swagger UI, which loads automatically at the application root when running in development mode.
